# emgncy-edu

## Демо-стенд

Приложение работает на моковых данных: бэкенд не подключён, авторизации нет, роль выбирается
по учётной записи и хранится до закрытия вкладки. Вход выполняется одной из трёх
демонстрационных учёток, пароли временные и действуют только на стенде.

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `admin123` | администратор |
| `teacher` | `teacher123` | преподаватель |
| `student` | `student123` | обучающийся |
