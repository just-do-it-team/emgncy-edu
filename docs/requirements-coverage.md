## Резюме

**Покрытие роли «Преподаватель» — 80 %.** Из 20 пунктов ТЗ §8: 12 сделано, 8 частично, 0 не
сделано; частичные считаются за половину. По пути «Настройка учебной среды»: 2 шага из 9 сделано,
4 частично, 3 не сделано.

Самые сильные пункты для защиты:

1. **Монитор занятия с нормативами заказчика.** Лента тревог по 30 с и 3 мин считается по журналу
   действий, живые таймеры, бездействие, прерывание с причиной — ровно «удалённый контроль» из Q&A.
2. **ИИ под контролем преподавателя.** Генерация сценария по классификатору, «ИИ предлагает
   сложность», частичное и полное подтверждение эталона. Утверждение и назначение обучаемым
   невозможны, пока эталон не проверен.
3. **Преподаватель — конечный валидатор.** Экспертная оценка заменяет автоматическую везде, где
   виден балл; «Не считаю ошибкой»; изменение оценки только с причиной.
4. **Прозрачный разбор попытки.** Итог → критерий → поле → момент в журнале и в записи звонка;
   посимвольная подсветка ошибок в адресе.
5. **Отчёт занятия и «Разбор ИИ» с честным запасным вариантом.** Типичные ошибки группы,
   рекомендации, заметки по обучаемым, PDF. Без сервиса ИИ — алгоритмический разбор с явной
   подписью, а не пустой экран.
