# Глоссарий

Термины этого глоссария — единственно верные. В коде, типах, названиях переменных и
текстах интерфейса используются именно они, без синонимов и переводов.

| Термин | Значение |
|---|---|
| Система-112 | Система приёма вызовов по единому номеру «112», регистрации и передачи информации в службы |
| ПОВ-112 | Информационная система системы-112 Москвы. Именно её интерфейс копируется |
| КИС УСС | Комплексная информационная система, в которую входит ПОВ-112 |
| АРМ-112 | Автоматизированное рабочее место. Два режима: оператор Службы 112 (заводит карточку) и диспетчер ДДС (обрабатывает поступившую) |
| ДДС | Дежурно-диспетчерская служба — получатель карточки, реагирует |
| ВИС | Внешняя информационная система (Служба 101, 102, 103, 104, ЦОДД, Мосводоканал и др.) |
| ЕКП | Единый классификатор происшествий. Дерево признаков → итоговый тип → список оповещения |
| Опросная карта | Форма признаков происшествия, разворачивается после выбора типа. Строится из ЕКП, не хардкодится |
| Формализованные признаки | Признаки 1, 2, 3 уровня. Их комбинация однозначно даёт итоговый тип |
| Итоговый тип происшествия | Результат разрешения признаков по ЕКП. Определяет список оповещения |
| Список оповещения | Набор служб, оповещаемых автоматически. В среднем 10 служб, максимум 23 |
| Главная служба | Профильная служба типа. В интерфейсе подчёркнута двойной линией. Пропуск — критическая ошибка |
| Отработка | Запись о звонке в службу, не оповещённую автоматически: служба, куда звонили, телефон, кто принял, суть |
| АОН | Автоматически определившийся номер заявителя |
| Описательный адрес | Адрес словами, когда точного нет: «напротив пруда», «рядом с ТЦ» |
| Статус заявителя | очевидец, пострадавший, родственник, знакомый, ребёнок, участник |

Заявитель — тот, кто звонит. Обучающийся — тот, кого тренируют. Оператор — роль,
которую обучающийся играет. Преподаватель ведёт занятие. Не смешивать.
