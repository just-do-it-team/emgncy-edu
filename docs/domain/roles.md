# Роли

| Роль | Может | Не может |
|---|---|---|
| Обучаемый | свои задания, свои результаты, свои ошибки | чужие результаты, правка материалов и оценок |
| Преподаватель | сценарии, занятия, оценки с обязательным комментарием, отчёты | системные настройки, вмешательство в занятия других преподавателей |
| Администратор | учётные записи, сервисы, журналы, бэкапы | менять оценки и сценарии во время активного занятия |

Ограничения ролей реализуются как явные блокировки с поясняющим тултипом, а не
скрытием без объяснения: эксперт на защите будет их проверять.
