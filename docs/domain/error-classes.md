# Классы ошибок

| Класс | Примеры | В интерфейсе |
|---|---|---|
| Критическая | пропуск главной службы, ошибка в топониме или номере дома, статус без обязательного комментария, промах по адресу > 500 м | `red` `#ff0000` |
| Значимая | пропуск неглавной службы, искажение смысла в описании, превышение норматива | `orange-2` `#ed933b` |
| Незначительная | опечатки в описании, регистр, пунктуация | нейтральный |

Отдельный случай — неоднозначный топоним. В Москве есть улица Дубнинская и улица
Дубининская; ошибка отправляет реагирование по другому адресу. Такие ошибки
показываются с обоими вариантами и пояснением последствия.
