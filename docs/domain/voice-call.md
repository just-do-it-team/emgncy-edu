# Голосовой звонок

**Звонок есть, софтфона нет.**

Голосовой диалог с заявителем на бэкенде реализован полностью: приём реплики обучаемого,
распознавание речи, ответ заявителя от диалоговой модели, синтез речи и посегментная выдача
через SSE. Контракт — `docs/api/realtime.md`.

Речь в оценке не участвует: результат входящего звонка определяется сравнением сохранённой
карточки с эталоном, а разговор нужен для воспроизведения диалога
(`backend/src/s112/api/student/audio_messages/README.MD`).

Интерфейс при этом **не проектируется вокруг софтфона**. У обучаемого нет набора номера,
перевода вызова, удержания линии и списка контактов. Он принимает входящий вызов, говорит
и завершает — всё.
