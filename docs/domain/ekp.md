# ЕКП как источник истины

Оценка действий обучающегося детерминирована и вычисляется из ЕКП. LLM не решает,
правильный ли ответ.

Цепочка: признаки 1 → 2 → 3 уровня → итоговый тип → тип ЕКП-35 → главная служба →
список оповещения. В классификаторе 1281 итоговый тип и 637 типов ЕКП-35.

Для фронта это значит:
- опросные карты строятся из дерева ЕКП, а не пишутся руками;
- разбор ошибки ссылается на конкретный признак: «не выбран признак „Есть угроза
  людям“ → не оповещён ЦЭМП»;
- балл и список ошибок приходят с бэкенда. Клиент их отображает, не пересчитывает
  и не «улучшает».
