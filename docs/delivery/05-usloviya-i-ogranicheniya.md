# 5. Условия и ограничения

## 5.1. Контур и сеть

- Решение работает в изолированном локальном контуре. Фронтенд не делает внешних запросов:
  шрифт, иконки, словарь орфографии и классификатор входят в сборку.
- Все модели (распознавание, синтез, языковая модель) работают локально. Веса размещаются
  на сервере вручную.
- Вход в контур один — nginx (порты 80 и 443). Внутренние порты сервисов наружу не публикуются.

## 5.2. Требования к серверу

| Ресурс | Требование |
|---|---|
| ОС | Linux с Docker Engine и Docker Compose v2 |
| GPU | NVIDIA с драйвером и NVIDIA Container Toolkit — обязательно для speech-api. Сборка по умолчанию под архитектуру CUDA 7.5 (RTX 2060 и новее); для другой карты задаётся `CUDA_ARCHITECTURES` |
| CUDA | Образ собирается на CUDA 13.0.2 с cuDNN, PyTorch 2.10 (cu130) |
| Языковая модель | Отдельный процесс llama-server с моделью gpt-oss-20b, доступный контейнерам по `host.docker.internal:4555`. Требования к его ресурсам зависят от выбранной квантизации и в репозитории не зафиксированы |
| CPU, RAM, диск | По ТЗ для ИИ-модуля: от 6 ядер, от 32 ГБ ОЗУ, NVMe от 512 ГБ. Точные замеры потребления стека не проводились |
| Сеть | Доменное имя, указывающее на сервер, если нужен сертификат Let's Encrypt; без TLS — локальный запуск по разделу 6 |

## 5.3. Рабочее место обучаемого

- Браузер: актуальные Chrome, Firefox, Яндекс.Браузер. Разрешение экрана от 1440 px по ширине
  рекомендуется для АРМ; кабинеты работают и на узких экранах.
- Гарнитура с микрофоном. Браузер разрешает доступ к микрофону только в защищённом контексте:
  по HTTPS или с `localhost`. По незащищённому HTTP с другого адреса голосовой звонок работать
  не будет.
- Сессия хранится в памяти вкладки: после перезагрузки страницы нужно войти заново, новая
  вкладка тоже требует входа. Незавершённая попытка продолжается с «Обзора».

## 5.4. Что не поддерживается

| Возможность | Статус |
|---|---|
| Телефония SIP/VoIP, IP-телефон | Не поддерживается. Голос передаётся через браузер (запись реплик и воспроизведение синтеза). Софтфона, набора номера, перевода и удержания вызова нет |
| Дообучение модели загрузкой материалов | Нет: ручек загрузки файлов и обучения на стороне сервера нет |
| «Уточнить у ИИ» — перегенерация шаблона по текстовому комментарию | Нет: ручка генерации принимает только набор служб |
| Настройка нормативов преподавателем | Нет: 30 с и 3 мин фиксированы по уточнению заказчика |
| Прерывание индивидуальной попытки преподавателем | Нет: сервер разрешает преподавателю прерывать только попытки на общем рабочем месте; индивидуальную попытку прерывает сам обучаемый |
| Отмена и перенос занятия, по которому уже были попытки | Нет: сервер отвечает отказом (409) |
| Удаление групп, сценариев и шаблонов | Только архив и деактивация; назначенные занятия хранят снимок сценария |
| Номер рабочего места в отчёте | В данных попытки его нет; в отчёте указывается служба |
| Мобильная версия АРМ | Нет; кабинеты адаптированы под узкие экраны без изменения раскладки |

## 5.5. Известные ограничения

| Ограничение | Пояснение |
|---|---|
| Тайминг решения на сервере | Сервер считает 180 с от открытия карточки до решения без требования текста. Монитор и отчёты во фронтенде считают по уточнению заказчика: 3 мин от появления до первой записи со статусом и текстом. Расхождение описано в `docs/api/open-questions.md`, раздел 12 |
| Ответ PATCH сценария и группы | Сервер применяет правку, но может ответить ошибкой 500 после сохранения. Фронтенд перечитывает сущность и показывает результат корректно |
| Проверка роли в admin-api | Admin-api требует действующий токен, но роль администратора не проверяет; на уровне интерфейса раздел доступен только администратору |
| Резервное копирование | В составе стенда нет: действия резервного копирования и восстановления в панели администратора возвращают отказ. Настройка — зона эксплуатации (регулярный дамп PostgreSQL и томов SeaweedFS) |
| TLS | Только на входе в контур (nginx + Let's Encrypt). Внутренний трафик между контейнерами, включая Kafka, не шифруется. Продление сертификата нужно запланировать на сервере |
| Хранение журналов | Loki хранит журналы 7 суток, Prometheus — метрики 15 суток. Требование ТЗ о 6 месяцах выполняется настройкой хранения при развёртывании; журнал действий попыток и аудит администратора хранятся в PostgreSQL и автоматически не удаляются |
| Модуль журналов admin-api в репозитории | Каталог `backend/src/s112/admin_api/logs/` попадает под правило `logs/` в `.gitignore` и в репозиторий не входит, хотя `admin_api/main.py` его импортирует. На стенде модуль есть и admin-api работает; из чистой копии репозитория admin-api не запустится, пока модуль не добавлен (исключение в `.gitignore`) |
| Отказоустойчивость PostgreSQL | Реплика обслуживает чтение; автоматического переключения на неё при отказе основного узла нет |
| Администратор | Учётной записи администратора в начальных данных нет, её создаёт эксплуатация |
| Воспроизводимость сборки речевого сервиса | Часть зависимостей не закреплена по версии: GigaAM ставится с ветки `main`, llama.cpp — с `master`, часть пакетов Python задана диапазоном. Для промышленной сборки версии нужно закрепить |
| Орфография | Словарная проверка без контекста: возможны ложные срабатывания на редких словах и пропуски ошибок, дающих существующее слово |
| Прогноз | На малой истории неточен; интерфейс явно помечает выводы как предварительные |
| Аналитика | Считается в браузере: для каждой попытки периода загружается контекст оценки. На большой истории страница загружается дольше |
