# 8. Ограничения, допущения, известные ошибки

Раздел отвечает на требование ТЗ, разд. 13: условия и ограничения внутри решения. Состояние проверено на стенде и по коду 29.09.2026.

## 8.1. Допущения

- Эталон шаблона — единственный источник правильного ответа. Что не задано в эталоне, не проверяется.
- Описание происшествия и комментарии к статусам сервер не оценивает: они хранятся для разбора, орфография показывается отдельно.
- Адрес в эталоне записывается как «г. Москва, улица, дом…» без округа и района.
- Нормативы 30 с и 3 мин фиксированы по уточнению заказчика и относятся к карточке ДДС. Для оператора 112 норматива нет.
- Голос заявителя синтезируется по референсным записям из каталога моделей. Права на эти записи не зафиксированы (раздел 5.8).

| Возможность | Статус |

| Настройка нормативов преподавателем | Нормативы фиксированы |
| Запуск общего рабочего места преподавателем | Политика `TEACHER_START` есть в API, кнопки запуска в интерфейсе нет |
| Ручной вброс карточки из монитора | Ручка сервера есть, в интерфейсе монитора не подключена |
| Прерывание индивидуальной попытки преподавателем | Сервер разрешает преподавателю прерывать только попытки общего рабочего места |
| Отмена и перенос занятия с попытками | Сервер отвечает 409 |
| Удаление групп, сценариев и шаблонов | Только архив и деактивация |
| «Разбор ИИ» занятия моделью | Ручки на сервере нет, показывается алгоритмический разбор с явной подписью |
| Решения преподавателя по отдельным расхождениям | Сервер хранит только итоговую оценку и комментарий |
| Номер рабочего места в отчёте | В данных попытки его нет, указывается служба |
| Мобильная версия АРМ | Нет; кабинеты адаптированы под узкий экран |
| Резервное копирование, пакетные обновления, управление сервисами из панели | Разделы есть, действия на сервере отключены и возвращают 423 |
| Выгрузка xlsx, сертификаты PDF, конфигурации XML | Нет |

## 8.4. Ограничения инфраструктуры и безопасности

Таблица 45 — Ограничения инфраструктуры и безопасности

| Ограничение | Пояснение |
|---|---|
| TLS | Только на входе в контур (nginx, Let's Encrypt). Внутренний трафик между контейнерами, включая Kafka, не шифруется. Продление сертификата нужно поставить в расписание |
| Резервное копирование | В составе стенда нет. Регулярный дамп PostgreSQL и томов SeaweedFS настраивается при развёртывании |
| Хранение журналов | Loki — 7 суток, Prometheus — 15 суток. Требование 6 месяцев выполняется настройкой хранения; журнал действий попыток и аудит администратора хранятся в PostgreSQL и автоматически не удаляются |
| Аудит изменения оценки | Изменение пишется в журнал попытки с причиной в комментарии; в аудит admin-api текст причины не попадает |
| Отказоустойчивость PostgreSQL | Реплика обслуживает чтение; автоматического переключения при отказе основного узла нет |
| Сессия пользователя | Токен живёт в памяти вкладки и в её `sessionStorage`: перезагрузка страницы сессию сохраняет, новая вкладка требует входа. Через 1 ч токен истекает, если не продлён |
| Администратор | Учётной записи администратора в начальных данных нет, её создаёт эксплуатация |
| Воспроизводимость сборки речевого сервиса | GigaAM ставится с ветки `main`, llama.cpp — с `master`, часть пакетов Python задана диапазоном; lock-файла для Python нет |
| Производительность | Нагрузочное тестирование не проводилось. Ответ заявителя — 5,7–7,4 с до первого звука (раздел 3.11) |

## 8.5. Ограничения методов

- **Орфография** — словарная проверка без контекста: возможны ложные срабатывания на редких словах и пропуски ошибок, дающих существующее слово.
- **Прогноз** на малой истории неточен; интерфейс помечает выводы как предварительные при числе пар меньше 10.
- **Аналитика** считается в браузере: для каждой попытки периода загружается контекст оценки, на большой истории страница загружается дольше.
- **Смысловая проверка доклада** зависит от модели. Недоступность модели помечается как «проверка не выполнена», а не как ошибка обучаемого.
