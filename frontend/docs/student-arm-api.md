# Учебное рабочее место

Занятия на странице `/student` — демонстрационные. Параметр `lesson` в `/student/arm`
определяет роль через `studentLessons`; неизвестное занятие показывает ошибку.
Оба режима открываются со списка карточек. У оператора 112 есть отдельная шапка
с часами и кнопкой «Создание карточки». Существующая карточка открывается в режиме
просмотра; «Дополнить карточку» включает редактирование. Создание открывает пустую
форму, сохранение добавляет новую строку в журнал. Независимые карточки 112
сохраняются по занятию в памяти вкладки до перезагрузки страницы. Статусы ДДС
сохраняются при закрытии и повторном открытии карточки в текущем рабочем месте.
Это не завершение серверной попытки и не оповещение реальных служб.

## Классификатор

`src/entities/incident/data/incident-classifier.json` — неизменённая копия
`backend/outputs/incident_classifier_reference.json`, версия 2.0.0, 1283 записи.
Источник следует обновлять целиком при изменении справочника бэкенда.

Выбор статистической группы и трёх определяющих признаков разрешается в запись.
Строки с признаком «Не отображается оператору 112» исключены из выбора.
Если одинаковые текстовые признаки соответствуют нескольким записям (БПЛА / БВС
в регионе), требуется дополнительный выбор итогового типа, первая запись
не подставляется автоматически. Смена признака сбрасывает зависимые признаки.

Оповещение учитывает условия `route_definitions` и дополнительные флаги.
Отрицательные ветки отключаются при выборе положительных, совпадающие службы
объединяются. Значения «нет реагирования», «Без оповещения» и «По согласованию»
не включаются в автоматическое оповещение. Службу можно добавить вручную.
Условия «пеш», «ав» и «>5 чел / ОД» перенесены из справочника; их смысл и
полноту правил следует согласовать с предметным экспертом перед оценкой учащихся.
Территориальные службы пока отображаются группами справочника, без разрешения
адреса в конкретную территориальную ДДС.

## Доступные API

Проверены локальные README бэкенда и OpenAPI сервера
`http://78.36.74.22:8080/openapi.json` (22.09.2026).

| Функция                 | Метод                                                       | Состояние подключения                                 |
| ----------------------- | ----------------------------------------------------------- | ----------------------------------------------------- |
| Справочник служб        | `GET /api/v1/services`                                      | Подключён опционально для ручного добавления службы   |
| Назначения обучающегося | `GET /api/v1/scenario-assignments?participant_user_id=UUID` | Нужен UUID из сессии пользователя                     |
| Название сценария       | `GET /api/v1/training-scenarios/{id}`                       | Получается отдельно от назначения                     |
| Запуск                  | `POST /api/v1/scenario-assignments/{id}/start`              | Нужны `user_id`, сохраняемый `Idempotency-Key`        |
| Карточки АРМ            | `GET /api/v1/workspaces/{id}/cards` и `.../{cardId}`        | Нужны workspace и `X-User-Id`                         |
| Получение и решение ДДС | `POST .../{cardId}/open`, `POST .../{cardId}/decision`      | Только своя служба; для отказа требуется комментарий  |
| Изменения карточки      | `PATCH /api/v1/cards/{id}`, `PUT .../features`              | Нужна версия карточки и обработка 409                 |
| Статусы службы          | `POST /api/v1/card-services/{id}/statuses`                  | Требуется серверный UUID связи карточки и службы      |
| Завершение              | `GET .../completion-readiness`, `POST .../complete`         | Зависит от политики завершения и выполненных действий |

Для живого справочника задайте `VITE_ARM_API_URL=http://78.36.74.22:8080` и
перезапустите фронтенд вручную. Без переменной используются названия из локального
классификатора. Ошибка сервера явно показывается, без скрытой подмены моками.
CORS сервера должен разрешать origin фронтенда; при HTTPS нужен HTTPS API или
same-origin reverse proxy. Настройки остальных страниц не меняются.

Полноценное прохождение не включено: демонстрационная сессия фронтенда хранит
только роль, в назначении нет явного режима ARM112/DDS. `workspace_mode` означает
INDIVIDUAL/SHARED и не подходит для выбора интерфейса. Нужно согласовать источник
режима и связать авторизацию с UUID пользователя. Серверные справочники типов
сейчас представляют отдельное дерево идентификаторов; номера из JSON нельзя
передавать как UUID или ID серверных признаков без подтверждённого сопоставления.
Голос, SSE, серверное сохранение, завершение и оценка в текущий макет не входят.
