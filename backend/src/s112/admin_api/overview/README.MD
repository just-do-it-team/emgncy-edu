# Вкладка «Обзор»

API предоставляет агрегированное состояние демонстрационного стенда. Все методы
доступны только для чтения. Временные метки возвращаются в UTC по ISO 8601.

## `GET /api/v1/admin/overview`

Главный запрос вкладки. Возвращает:

- `status`: `healthy`, `degraded` или `unavailable`;
- `components`: количество исправных и обязательных целей, а также число
  недоступных опциональных экспортёров;
- `firing_alerts`: число активных алертов;
- `errors_24h`: число ошибок в Loki за 24 часа;
- `host`: CPU, RAM, диск, сеть и uptime Linux-сервера;
- `gpu`: доступность `nvidia_gpu_exporter`, загрузку, VRAM, температуру и мощность;
- `postgres_up`: доступность основной PostgreSQL;
- `kafka_brokers` и `kafka_consumer_lag`;
- `warnings`: недоступные источники или отдельные метрики.

Значение `null` означает, что метрика ещё не была собрана или соответствующий
экспортёр не запущен. Это не следует отображать как нулевую нагрузку.

Пример фрагмента ответа:

```json
{
  "generated_at": "2026-09-19T10:00:00Z",
  "status": "degraded",
  "components": {"healthy": 9, "total": 10, "optional_unavailable": 1},
  "firing_alerts": 1,
  "errors_24h": 4,
  "host": {"cpu_percent": 31.5, "memory_percent": 62.1},
  "gpu": {"available": true, "utilization_percent": 71.0}
}
```

Frontend рекомендуется обновлять раз в 10–15 секунд. Если `warnings` не пуст,
нужно показать неблокирующее предупреждение о неполных данных.

## `GET /api/v1/admin/overview/components`

Возвращает цели Prometheus с полями `name`, `instance`, `status`,
`last_scrape_at`, `scrape_duration_seconds` и `error`. Используется для списка
компонентов и перехода к диагностике. Обновление раз в 15–30 секунд.

## `GET /api/v1/admin/overview/events`

Параметры:

- `hours` — период от 1 до 168 часов, по умолчанию 24;
- `limit` — от 1 до 200 записей, по умолчанию 20.

Возвращает последние предупреждения и ошибки: `timestamp`, `service`, `level`,
`message`, `labels`. Клик по записи может открывать вкладку журналов с уже
заполненными фильтрами сервиса и периода.

## Ошибки

- `502` — Prometheus или Loki недоступен;
- `422` — параметры не прошли проверку диапазона.
