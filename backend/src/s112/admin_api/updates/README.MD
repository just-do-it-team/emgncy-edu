# Вкладка «Обновления»

- `GET /api/v1/admin/updates/status` — состояние проверки и число доступных пакетов;
- `GET /api/v1/admin/updates/packages` — установленные и доступные версии;
- `POST /api/v1/admin/updates/actions/check` — запрос проверки;
- `POST /api/v1/admin/updates/actions/apply` — тело `{"packages":["..."]}`.

Проверка репозиториев и установка пакетов на демонстрационном стенде отключены:
они могут изменить его состояние. Поэтому статус равен `disabled`, список
пуст, а обе команды возвращают `423 operation_disabled` и попадают в аудит.
Frontend должен отображать экран как намеренно заблокированный, а не как сбой.
